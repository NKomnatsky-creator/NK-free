# PassVault / NK Secure — Free

Открытая free-сборка: до 5 пользователей, управление паролями, папки доступа,
импорт/экспорт, центр безопасности, уведомления, 2FA, API-токены, LDAP/OIDC,
мастер-пароль и браузерное расширение.

Резервные копии, общие ссылки и брендинг входят в Enterprise и в этой сборке
недоступны. Публичный код не содержит Enterprise-модулей.

## Быстрый запуск

```bash
python -m pip install -r requirements.txt
python start.py
```

Откройте `http://localhost:8000`. Логин: `admin`. Пароль задаётся переменной
`DEFAULT_ADMIN_PASSWORD` или генерируется при первом запуске и выводится в лог.

## Docker

Готовый образ:

```bash
docker run -d --name nk-free -p 8000:8000 \
  -v nk-data:/data \
  -e DEFAULT_ADMIN_PASSWORD='смените-на-свой' \
  ghcr.io/NKomnatsky-creator/nk-free:latest
```

Или соберите из исходников:

```bash
docker compose up -d --build
```

База данных, ключ шифрования и `.flask_secret` хранятся в `/data`
(volume `nk-data`) и сохраняются при пересоздании контейнера. Для прямого
доступа по HTTP ничего дополнительно настраивать не нужно; за HTTPS-прокси
задайте `HTTPS=1` и `TRUSTED_PROXY_COUNT=1`. При включённом мастер-пароле
передайте `MASTER_PASSWORD`. Healthcheck проверяет порты 8000 и 5000.

## Что реализовано

- управление паролями, папки доступа, роли admin / manager / user;
- импорт и экспорт (CSV/JSON с фильтрами);
- центр безопасности: слабые, повторяющиеся, утечка, старые и истёкшие пароли;
- уведомления;
- TOTP-2FA и коды восстановления;
- API-токены (`Authorization: Bearer pt_...`);
- журнал событий с фильтрами и экспортом CSV;
- внешняя аутентификация: LDAP и OIDC (PKCE) с автопровижинингом пользователей;
- мастер-пароль с PBKDF2 и перешифрованием хранилища (`master.py`);
- браузерное расширение Manifest V3 для автозаполнения (`browser-extension/`);
- Docker Compose и пример HTTPS-конфигурации nginx.

Подробности развёртывания и переменные окружения — в [DEPLOY.md](DEPLOY.md).

## Важно

- Внутренний сервер слушает `127.0.0.1:5000` и не должен быть доступен извне.
- Для доступа по сети используйте HTTPS и обратный прокси.
- Храните `secret.key`, `.flask_secret` и базу данных в защищённом месте.
- С включённым мастер-паролем `secret.key` удаляется: потеря пароля означает
  потерю доступа к данным.
