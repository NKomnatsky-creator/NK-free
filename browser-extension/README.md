# NK Secure Autofill — браузерное расширение

Расширение Manifest V3 для Chrome/Edge/Firefox. Подставляет логин и пароль из вашего хранилища NK Secure на любой странице через REST API и персональный API-токен.

## Установка

1. Откройте `chrome://extensions` (или `about:debugging` в Firefox).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `browser-extension`.

## Настройка

1. Войдите в NK Secure и откройте **Центр безопасности → API-токены**.
2. Создайте токен (срок действия — по необходимости) и скопируйте его. Токен показывается только один раз.
3. Откройте расширение, укажите:
   - адрес сервера, например `http://localhost:8000`;
   - токен вида `pt_...`.
4. Нажмите «Сохранить», затем «Обновить список».

Данные хранятся только в `chrome.storage.local` и не синхронизируются с аккаунтом браузера.

## Использование

- **Вставить** — ищет первое поле пароля и поле логина на активной вкладке и заполняет их.
- **Копировать** — копирует пароль в буфер обмена.

Расширение внедряет код на активную вкладку только по вашему действию (разрешение `activeTab`). Для localhost доступ уже есть; при сохранении другого адреса расширение само запросит разрешение на этот origin через `optional_host_permissions`.

## Безопасность

- Токен передаётся в заголовке `Authorization: Bearer` и не попадает в URL или логи.
- Пароли не кэшируются расширением и не отправляются никуда, кроме активной страницы/буфера.
- Для продакшена используйте HTTPS и токен с минимальным сроком действия.
